Fundação Desacoplada

Compatibilidade Universal com Zero Runtime

A camada @magic-style/css é completamente agnóstica de framework. Use componentes ricos em Vue 3 ou integre as classes semânticas puras em qualquer ecossistema.

Vue 3 & Nuxt

Pacote oficial @magic-style/vue com 82 componentes, TypeScript estrito e suporte nativo a v-model.

React & Next.js

Consuma a camada @magic-style/css diretamente com classes semânticas .ms-*.

Svelte & SvelteKit

Zero JavaScript em tempo de execução nas folhas de estilo, com compatibilidade imediata.

HTML Estático & Astro

Sem compilador de CSS obrigatório: importe uma única folha de estilos e pronto.
