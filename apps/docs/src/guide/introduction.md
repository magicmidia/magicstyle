# Introduction

Magic-Style is a design system for Vue 3: accessible components, themes defined by a 27-variable CSS contract, and flash-free SSR. It is built with Laravel + Inertia apps in mind, but works in any Vue 3.5+ app.

```vue
<script setup lang="ts">
import { MsButton, MsField, MsInput } from "@magic-style/vue";
</script>

<template>
  <MsField label="Email" description="Used to sign in">
    <MsInput type="email" name="email" autocomplete="email" />
  </MsField>
  <MsButton>Save</MsButton>
</template>
```

## Packages

| Package            | What it ships                                                                              |
| :----------------- | :----------------------------------------------------------------------------------------- |
| `@magic-style/vue` | 95 Vue 3 components in strict TypeScript, plus composables and theme/i18n utilities.       |
| `@magic-style/css` | Framework-free CSS: tokens, 10 themes with light and dark modes, semantic `.ms-*` classes. |

The Vue components ship no styles of their own. All visuals come from `@magic-style/css`, which also works on its own in plain HTML or Blade.

## Principles

- **Contract-based theming.** A theme sets 27 variables. Hover, focus, borders, text and shadows are derived from them in CSS. See [Theming](/guide/theming).
- **Accessible by default.** Components follow WAI-ARIA APG patterns and target WCAG 2.2 AA, with axe-core audits and contrast tests across every theme. See [Accessibility](/guide/accessibility).
- **SSR first.** Every component renders on the server, and the `system` color mode is resolved in CSS, with no flash and no hydration mismatch. See [SSR](/guide/ssr).
- **Three built-in languages.** Strings generated by the components default to English, with Portuguese and Spanish included. See [Internationalization](/guide/i18n).
- **Real RTL.** The CSS uses logical properties. See [RTL](/guide/rtl).
- **Easy to override.** All CSS lives in the `ms` cascade layer, so your app's CSS always wins.
