# Tokens

Magic-Style organiza los tokens en tres capas. Los valores y las vistas previas siguen el tema y el modo elegidos en **Personalizar**, en la barra superior. Haz clic en el nombre de un token para copiar `var(--ms-…)`.

<TokenExplorer />

## Formatos

- **CSS:** las variables `--ms-*` vienen en `@magic-style/css` (`tokens.css` y `themes.css`).
- **DTCG:** los tokens primitivos siguen el formato del W3C Design Tokens Community Group y pueden alimentar Figma (Tokens Studio) o Style Dictionary.
- **TypeScript:** el contrato está disponible como `MS_THEME_CONTRACT`, y `defineMsTheme` autocompleta sus claves. Consulta la [galería de temas](/es/themes).
