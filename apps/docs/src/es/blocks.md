# Bloques

Pantallas listas construidas solo con componentes de Magic-Style: sin bibliotecas extra ni imágenes, solo Vue y design tokens. Cambia el ancho de la vista previa para ver cómo cada bloque se adapta a 375 px, 768 px y ancho completo; luego abre la pestaña de código y cópialo en tu app.

Tarjeta de inicio de sesión centrada con correo, contraseña, recordarme, acceso social y enlace de registro.
