# Magic-Style — Architecture Baseline 1.2

Coleção consolidada da documentação do projeto Magic-Style.

**Consolidação:** 2026-08-25

## O que mudou na Baseline 1.2

- qualidade visual premium como requisito normativo;
- Application Layout System first-class;
- responsividade universal para viewport, container e touch;
- `MsSelect` avançado unificado;
- DataTable, Calendar, Charts e Notifications como subsistemas standalone;
- alta customização via tokens/themes/slots/props semânticas/Open Code;
- Reference Application e Visual Integration Gate.
