# CHANGELOG — Architecture Baseline 1.2

## 2026-08-25 — Baseline 1.2

### Visual
- Qualidade moderna, bonita, refinada e consistente elevada a requisito stable/release.
- Visual Integration Gate e Reference Application adicionados.

### Application Layout
- AppShell, Topbar, Sidebar, Navigation Rail, Toolbar/Toolset, Content/Main, Aside, Footer, StatusBar, Split View e Resizable Panels formalizados.

### Responsive
- Responsive-by-design para toda a biblioteca, incluindo container queries, touch/pointer e adaptação de padrão de interação.

### Select
- `MsSelect` consolidado como engine avançado unificado; `MsNativeSelect` preservado.

### Standalone Subsystems
- DataTable, Calendar, Charts e Notifications formalizados e isoláveis do core.
