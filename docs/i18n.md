# Idioma dos componentes (i18n)

Os componentes geram alguns textos por conta própria: nomes acessíveis (`aria-label` de botões de fechar, paginação, carrossel…), placeholders padrão, estados vazios e nomes de mês e dia do `MsDatePicker`. Esses textos vêm de um dicionário tipado. O padrão é **português (pt-BR)**, e **inglês** e **espanhol** vêm inclusos.

As props de texto continuam valendo mais que o dicionário: `placeholder`, `emptyText`, `confirmLabel` e similares sobrescrevem a mensagem só naquela instância.

## Trocar o idioma

No app inteiro, com o plugin:

```ts
import { createApp } from "vue";
import { createMsI18n } from "@magic-style/vue";

createApp(App)
  .use(createMsI18n({ locale: "en-US" }))
  .mount("#app");
```

Ou num trecho da árvore, com o `MsProvider`. Providers aninhados herdam o idioma do ancestral:

```vue
<MsProvider locale="en-US">
  <slot />
</MsProvider>
```

O `locale` é uma tag BCP 47. Ele escolhe o dicionário pelo idioma (`en-GB` usa o inglês, `es-MX` usa o espanhol) e formata datas com `Intl`. Por isso, meses e dias da semana do `MsDatePicker` saem no idioma certo, mesmo que o dicionário caia no português.

Com Laravel + Inertia, o idioma pode vir do backend como shared prop:

```vue
<script setup lang="ts">
import { usePage } from "@inertiajs/vue3";
import { MsProvider } from "@magic-style/vue";

const locale = usePage().props.locale as string; // ex.: app()->getLocale() no HandleInertiaRequests
</script>

<template>
  <MsProvider :locale="locale === 'en' ? 'en-US' : 'pt-BR'">
    <slot />
  </MsProvider>
</template>
```

## Ajustar textos ou criar outro idioma

`messages` aceita sobrescritas parciais. Só as chaves informadas mudam:

```vue
<MsProvider
  :messages="{ select: { empty: 'Nada encontrado' }, dialog: { close: 'Fechar janela' } }"
>
  …
</MsProvider>
```

Para um idioma completo, parta de um dicionário existente. O tipo `MsMessages` obriga a preencher todas as chaves:

```ts
import { createMsI18n, msMessagesEn, type MsMessages } from "@magic-style/vue";

const fr: MsMessages = {
  ...msMessagesEn,
  locale: "fr-FR",
  select: { ...msMessagesEn.select, placeholder: "Sélectionner...", empty: "Aucun résultat" },
  // …
};

app.use(createMsI18n({ locale: "fr-FR", messages: fr }));
```

Algumas mensagens são funções, porque dependem de valores: `carousel.slide(index, total)`, `datePicker.nextDays(days)` e `select.create(query)`.

A lista completa de chaves está no tipo `MsMessages` (`packages/vue/src/i18n/messages.ts`). Em componentes próprios, use `useMsMessages()` para ler o mesmo dicionário.
